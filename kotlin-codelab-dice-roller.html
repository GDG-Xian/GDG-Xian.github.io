Kotlin Codelab: 创建交互式 Dice Roller 应用

2023年3月14日

春暖花开的季节，很荣幸的宣布我们的 2023 年的第一场技术活动！

作为一个技术社区，我们这次以 Codelab 作为开胃菜激活大家的编码基因，一起探索移动端开发技术 Kotlin，本期的主题，是使用 Kotlin 开发一个 Dice Roller 应用。

https://developer.android.com/codelabs/basic-android-kotlin-compose-build-a-dice-roller-app?hl=zh-cn

在此 Codelab 中，您将创建一个交互式 Dice Roller 应用，让用户可以通过点按 Button 可组合项来掷骰子。掷骰子的结果将通过 Image 可组合项显示在屏幕上。

您可以将 Jetpack Compose 与 Kotlin 搭配使用来构建应用布局，然后编写业务逻辑来处理点按 Button 可组合项时发生的操作。

所需条件

  • 一台安装了 Android Studio 的计算机。

学习内容

  • 如何使用 Compose 向 Android 应用添加 Button 可组合项。
  • 如何使用 Compose 向 Android 应用中的 Button 可组合项添加行为。
  • 如何打开和修改 Android 应用的 Activity 代码。
  • 如何使用 Compose 在 Android 应用中显示 Image 可组合项。

构建内容

一款名为 Dice Roller 的交互式 Android 应用，可让用户掷骰子并向他们显示掷骰子的结果。
