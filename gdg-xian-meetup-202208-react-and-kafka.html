2022年9月活动 - React & Kafka

2022年8月9日

原本定于8月份的线下活动，因为疫情原因，我们已经该改期到9月18日，本次活动我们为大家准备了两个技术话题，分别涉及 React 和 Kafka。

同时，为了鼓励烂天气下依然热衷于参与社区活动的朋友们，我们为大家提供了 GDG 西安专属的解暑纪念品，希望大家追求技术的同时，也保护好自己的身体，预防中暑和晒伤。虽然相比8月份，9月已经不再炎热，大家权当留个纪念。

活动内容

2022年，如何多快好省的渲染你的React应用？

React生态已经今非昔比，从最初的单页面应用、客户端渲染，到现在的SSR，CSR，SSG百花齐放。在这次分享中，让我们一起来分析这些不同的React渲染技术，谈一谈自己对前端架构选型的看法，以及如何使用NextJs让你的开发事半功倍。

分享嘉宾：邓德瑞，Thoughtworks全栈开发工程师，一线TL，写了8年的代码，做过各种企业级Web应用，喜欢TypeScript，喜欢各种前端技术。

Kafka那些事

做一场关于kafka技术入门分享，说说它的生态，讲讲自己的生产实践经验。

分享嘉宾：杜鹏岩，Newegg架构师，西安IT技术圈社区发起人。

活动时间

2022年9月18日 周日 下午 1:30 - 4:30

注意：

  1. 本次活动与惯例不同，我们在周日下午举办，而不是周六
  2. 如果本月还无法进行线下活动，我们会改为线上，不再进行改期，具体请关注活动微信群。

活动地点

丈八四路20号，西安神州数码科技园4栋17楼，泥巴创客空间。（地铁六号线，丈八四路站A口出）

根据疫情防控要求，线下活动入场需要佩戴口罩并且配合场地提供方扫码测温。

活动报名

扫码关注 “GDG西安” 官方微信公众号，点击服务菜单中的 ”活动报名“，获取活动群二维码。入群既表示报名成功，活动相关的事宜我们会在群里通知。

GDG 西安的活动均为免费活动，任何对开发感兴趣的朋友，都欢迎报名参加。

微信群仅用于活动交流，入群后请勿随意发布广告等无关信息，谢谢合作。
